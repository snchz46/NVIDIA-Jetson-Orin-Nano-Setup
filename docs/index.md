# Documentation Index

Use this index to jump directly to the topic you need while preparing or maintaining the NVIDIA Jetson Orin Nano Developer Kit.

## Setup Workflow

1. [Hardware Assembly](hardware-assembly.md)
2. Download and verify the SD card image using the commands in the guide or the scripts in [`../scripts/`](../scripts/)
3. Flash the image from your host OS:
   - [Windows](windows.md)
   - [macOS](macos.md)
   - [Linux](linux.md)
4. [Troubleshoot](troubleshooting.md) any issues that arise during flashing or first boot.
