# NVIDIA-Jetson-Orin-Nano-Setup
Jetson Orin Nano Developer Kit Getting Started Guide

To prepare your microSD card, you’ll need a computer with Internet connection and the ability to read and write SD cards, either via a built-in SD card slot or adapter.

    Download the Jetson Orin Nano Developer Kit SD Card image from JetPack SDK Page , and note where it was saved on the computer.
    Write the image to your microSD card by following the instructions below according to the type of computer you are using: Windows, Mac, or Linux.
